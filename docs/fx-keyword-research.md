## タスク1: ペルソナ設計

### ペルソナA: FX初心者 —「佐藤 健太」

| 項目 | 詳細 |
|------|------|
| **年齢** | 28歳 |
| **職業** | IT企業の会社員（Webディレクター） |
| **年収** | 450万円 |
| **家族構成** | 独身、一人暮らし |
| **投資経験** | つみたてNISAを1年ほど継続中。個別株・FXの経験なし |
| **可処分所得** | 月5〜8万円を貯蓄や投資に回せる余裕がある |

**FXに興味を持ったきっかけ**
- YouTubeの投資系チャンネルで「FXで月5万円の副収入」という動画を見た
- 同僚がFXで利益を出しているという話を聞いた
- 円安ニュースを見て「為替で稼げるのでは」と思い始めた

**現在の悩み・課題**
- FXの仕組み自体がよくわからない（レバレッジ、スプレッド、ロット等の用語が不明）
- 「FXは危険」「借金する」というイメージがあり不安
- どのFX会社を選べばいいか判断基準がない
- 最低いくらあれば始められるのかわからない
- 本業が忙しく、学習に割ける時間が限られる

**情報収集の傾向**
- Google検索で「FXとは」「FX 始め方」などを調べる
- YouTube動画で視覚的に学ぼうとする
- X（Twitter）でFXトレーダーの投稿を見る
- 比較サイトやランキング記事を複数読む
- Yahoo!知恵袋やRedditで体験談を確認する

**意思決定の基準**
1. 少額（1,000通貨以下）から始められるか
2. 初心者向けの学習コンテンツ・デモ口座があるか
3. 口座開設の手軽さ（スマホ完結、本人確認の速さ）
4. 大手・知名度のある会社かどうか（安心感）
5. キャッシュバックなどのキャンペーン

### ペルソナB: 乗り換え検討者 —「田中 裕也」

| 項目 | 詳細 |
|------|------|
| **年齢** | 35歳 |
| **職業** | メーカー勤務の営業職 |
| **年収** | 600万円 |
| **家族構成** | 既婚、子ども1人（3歳） |
| **投資経験** | FX歴2年、株式投資歴3年 |
| **FX運用資金** | 約80万円 |

**FXに興味を持ったきっかけ（元々の動機）**
- 子どもの教育資金を効率的に増やしたいと考えた
- 株式投資だけでなくポートフォリオを分散したかった
- 平日夜にトレードできる点に魅力を感じた

**現在の悩み・課題**
- 現在のFX会社のスプレッドが広く、スキャルピングに向かない
- 取引ツール（チャート・注文機能）の使い勝手が悪いと感じている
- 約定力が低く、スリッページが頻発する
- スワップポイントが他社より低いことに気づいた
- 2年やって通算でほぼトントンor微損。手法を見直したい
- 乗り換え時に確定申告や資金移動が面倒に感じる

**情報収集の傾向**
- 「〇〇 FX スプレッド 比較」等の具体的な条件比較で検索
- FX専門メディア（ZAi、みんかぶFX等）を定期チェック
- X（Twitter）で中上級トレーダーの発信をフォロー
- FX会社の公式サイトでスペック詳細を直接確認
- 口コミ・レビューサイトでリアルな評判を調べる

**意思決定の基準**
1. スプレッドの狭さ（特にドル円、ユーロ円）
2. 取引ツールの高機能さ（TradingView連携、カスタムインジケーター）
3. 約定力・サーバー安定性
4. スワップポイントの水準
5. 口座移行のしやすさ（出金手数料無料、開設スピード）

## タスク3: 種キーワードリスト

種キーワードの一覧は別ファイル `seed-keywords.csv` に CSV形式で出力しています。

以下はカテゴリ別のサマリーです。

### 1. 情報収集系キーワード（15個）
FXの基礎知識・仕組み・リスクに関するキーワード。主に初心者の認知〜興味段階をカバー。

### 2. ハウツー系キーワード（15個）
始め方・やり方・口座開設手順など実践的な方法を求めるキーワード。検討段階が中心。

### 3. 比較・検討系キーワード（18個）
おすすめ・ランキング・比較など、意思決定を助ける商業的意図のキーワード。比較〜決定段階。

### 4. 具体的取引所名系キーワード（18個）
特定のFX会社名を含むキーワード。比較〜決定段階の指名検索。

### 5. 悩み・課題系キーワード（15個）
FXで勝てない・損した等のネガティブな課題に関するキーワード。乗り換え検討者に刺さる。

### 6. 乗り換え系キーワード（12個）
口座変更・解約・複数口座運用に関するキーワード。乗り換え検討者の全段階をカバー。

### 7. 手法・戦略系キーワード（15個）
具体的なトレード手法や戦略に関するキーワード。中級者の興味〜検討段階。

**合計: 108個**
